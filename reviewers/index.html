Redeeming your review code

If you received a PaceIQ code with a letter, this is where it goes.

  1. Install PaceIQ from the App Store and open it.
  2. Tap the gear button on the Last Workout screen to open Settings, then tap Redeem Code under About. You can also tap Redeem Code at the bottom of the Upgrade screen.
  3. Enter the code in Apple's Redeem Offer sheet and tap Continue.
  4. Once the code is accepted, Elite unlocks, and Settings shows your tier under Current Tier.
